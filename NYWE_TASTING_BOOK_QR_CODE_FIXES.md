# NYWE Tasting Book QR Code/URL Fixes

## Issue Summary
QR codes in the NYWE tasting book have errors - some link to wrong wineries, some have typos in URLs, and some are blocked/won't open.

---

## What System Manages These URLs?

Based on the code review:

**The winery website URLs come from Google Sheets** (the NYWE exhibitor roster sheets), specifically from the **"WINERY WEBSITE URL *"** column.

The contract portal system (`whiskyfest-contracts`) reads these URLs from Google Sheets but **does NOT generate the tasting book or QR codes**. 

**The tasting book and QR codes are likely generated by:**
- A separate InDesign/publishing workflow
- Or a separate script/tool that reads from the same Google Sheets

---

## Issues to Fix

### 1. Pages Linking to Wrong Winery

| Winery in Book | Issue |
|----------------|-------|
| Ca'Marcanda | Links to wrong winery |
| GAJA | Links to wrong winery |
| Pieve Santa Restituta | Links to wrong winery |

**Root cause:** Either the QR code was generated with the wrong URL, or the URL in the Google Sheet is wrong.

**Fix location:** Check/correct in:
1. Google Sheets (WINERY WEBSITE URL column)
2. The tasting book source files (InDesign/publishing tool)

---

### 2. Typos in URLs

| Winery | Current (Wrong) | Should Be (Correct) |
|--------|----------------|---------------------|
| Adriano Ramos Pinto | `www,` (comma) | `www.` (period) |
| Merum Priorati | `trura` | `tura` |
| Col d'Orcia | `.com` | `.it` |

**Example:**
- Wrong: `http://www,adrianoramospinto.com` or similar
- Right: `http://www.adrianoramospinto.com`

**Fix location:** 
1. **Google Sheets:** Correct the "WINERY WEBSITE URL *" column
2. **Tasting book source:** If URLs were manually entered in InDesign/publishing tool, fix there too
3. **Regenerate QR codes** with corrected URLs

---

### 3. Blocked or Non-Opening Links

| Winery | Issue |
|--------|-------|
| Beronia | Won't open |
| Brancaia | Won't open |
| CVNE | Won't open |
| Paolo Scavino | Won't open |
| Tensley | Won't open |

**Possible causes:**
1. **Dead/expired domain** - Website no longer exists
2. **Redirect issues** - URL redirects incorrectly
3. **HTTPS vs HTTP** - Mixed protocol issues
4. **Geoblocking** - Site blocks certain regions/IPs
5. **Typo in URL** - Slight misspelling makes it invalid

**How to diagnose:**
```bash
# Test each URL manually
curl -I https://www.winery-url.com
# or
curl -I http://www.winery-url.com
```

**Fix options:**
1. **Update to working URL** - Find winery's current website
2. **Add http:// or https://** - Ensure protocol is included
3. **Remove www.** - Try without www prefix (or add if missing)
4. **Contact winery** - Ask for their current correct URL
